🚀 90-Day Plan to Crack a Product / Remote Job

Foundation → Heavy Prep → Interview Cycle. Realistic dream target: ₹18–25 LPA Indian product co in 90 days at 80% execution.

📊 Probability Matrix (2 yrs Java + Spring Boot + Hyderabad, 20 hrs/week effort)

⏰ Daily Cadence (minimum 20 hrs/week, ideal 28)

  • Mornings 7–9 AM: DSA / interview prep (high cognitive load)
  • Lunch 1–1:30 PM: Apply to 5–10 jobs (low effort)
  • Evenings 8–11 PM: Prep + mock interviews + referral DMs
  • Weekends 10+ hrs: System design + deep prep + project work

🟢 Phase 1: Foundation (Days 1–14)

Goal: Build the pipeline + start prep cadence. Polish resume → upload everywhere (LinkedIn, Naukri, Instahyre, Foundit, Cutshort, Wellfound, Hirist, Arc.dev, Turing).

Week 1 deliverables

  • 10 DSA solved (5 easy + 2 medium Arrays, 3 medium Strings/HashMap)
  • 1 system design topic (URL Shortener — Gaurav Sen YouTube)
  • 1 mock interview on Pramp.com
  • 40+ applications (Naukri + LinkedIn Easy Apply)
  • 10 referral DMs to alumni

Week 2 deliverables

  • Register on Turing, Arc.dev, Toptal, Lemon.io, Micro1
  • Take Turing coding challenge (60 min) — milestone
  • 20 LeetCode total · 3 system design topics · 2 mocks · 50+ applies · 20 referrals

🔵 Phase 2: Heavy Prep + Apply (Days 15–60)

Goal: 100 LeetCode mediums + 10 system design topics + 5 interview invites.

LeetCode roadmap (NeetCode 150 order)

  • Week 3–4: Arrays, Strings, HashMap, Two Pointers, Sliding Window (40 problems)
  • Week 5–6: Trees, BFS/DFS, Backtracking, Recursion (30 problems)
  • Week 7–8: Dynamic Programming, Greedy, Graphs (30 problems)

5 behavioral STAR stories to prep

  • Most impactful project → Spring Boot 3 migration of 565 files

  • Why leave / Why this company → growth + scale + global teams

🟠 Phase 3: Interview Cycle (Days 61–90)

Goal: Convert prep into 5–15 interview invites and 1–3 offers.

Standard interview pipeline

  • HR call (15 min) — current/expected CTC, notice period, why looking
  • DSA round 1 (60 min) — 1–2 LeetCode mediums, live coding
  • DSA round 2 (60 min) — harder mediums or 1 hard
  • System Design (60 min) — typically asked for SE-II / Senior roles
  • Behavioral / Manager (45 min) — STAR stories
  • Offer + negotiation

Mock interview platforms (free)

  • Pramp.com — free peer-to-peer (highly recommended)
  • Interviewing.io — free for some
  • CodeSignal — free practice tests
  • Discord: LeetCode India, NeetCode servers

⚠️ 6 Things That Kill People in This Plan

  • Inconsistency. Missing 3 days = restart momentum. Daily streak = compound.
  • Tutorial hell. Watching DSA videos without coding = useless. Code every problem.
  • Applying without prep. Razorpay interview before ready = burns the bridge.
  • Negotiation cowardice. First offer is NOT the best. Always counter politely.
  • Resume tweaking obsession. Stop optimizing; start applying.
  • Comparing to others. Survivorship bias. Run YOUR plan.
